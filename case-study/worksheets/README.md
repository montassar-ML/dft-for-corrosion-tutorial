# Blank study worksheets

[Case overview](../README.md) · [Model card](model-card.md)

These are header-only CSV templates, **not datasets or computed results**. Leave values blank until supported. Zero means a genuine zero, not “not available.”

| File | Purpose |
|---|---|
| [convergence.csv](convergence.csv) | Numerical, model and sampling tests |
| [geometry.csv](geometry.csv) | Starting configurations and final distinct minima |
| [energies.csv](energies.csv) | Consistent electronic energy references and decomposition |
| [electronic_analysis.csv](electronic_analysis.csv) | Density/projection conventions, charge and work function |
| [coverage_environment.csv](coverage_environment.csv) | Surface density and environment definitions |
| [decision_log.csv](decision_log.csv) | Why a model/analysis choice was made |

Use stable IDs to relate rows to actual structures and raw outputs. This repository provides no raw DFT outputs and makes no numerical prediction.
